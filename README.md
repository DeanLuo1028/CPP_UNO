# UNO Console Game (C++)

這是一個用 C++ 實作的 UNO 遊戲範例程式，支援 2~10 名玩家，其中 1 名為人類玩家，其餘為簡單 AI 機器人。

## 🔎 專案介紹

程式採用純文字介面（Console）執行，遊戲資料結構包含：
- `Card`：代表一張 UNO 牌（顏色、功能/數值）
- `Deck`：牌庫、棄牌堆、洗牌及補牌邏輯
- `Player`：抽象類別，包含人類玩家與機器人玩家的共通邏輯
- `UNO`：遊戲流程控制（發牌、輪流出牌、特殊牌效果、勝利判定）

## ✅ 支援功能

- 遊戲規則支援：
  - 一般出牌 (顏色/數字相符)
  - Skip/Reverse/+2/+4
  - Wild 選色
  - 抽牌時若無可出牌則抽一張
- 機器人簡易出牌策略（優先出一般牌，其次出特殊牌）
- 可在遊戲結束後選擇重新開始

> 請注意：被+2與+4牌懲罰的人會被跳過

## 🧰 開發環境

本專案使用標準 C++ (至少需要支援 C++11) 進行編譯。

## ▶️ 快速執行

### 1. 編譯

```sh
g++ -Wall -Wextra -g3 uno.cpp -o output/uno.exe
```

### 2. 執行

```sh
./output/uno.exe
```
